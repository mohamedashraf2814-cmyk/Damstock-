# DAMSTOCK HOMES

Real estate marketplace mobile application for the Egyptian market.

Developed by **Soft Stream** — Software Programming & Digital Network.

## Requirements

- Flutter 3.24+
- Android Studio / Android SDK

## Getting started

```bash
flutter create . --org com.damstock --project-name damstock_homes --platforms=android,ios
flutter pub get
flutter run
```

Build a release APK:

```bash
flutter build apk --release
```

## Features

- Arabic (RTL) and English
- Onboarding and phone number sign-in
- Property listings with search, filters and sorting
- Developers and projects
- Resale and assignment listings
- Property comparison
- Interactive map
- Instalment calculator
- Viewing requests and inquiries
- Add property listing
- Favorites and user profile

## Project structure

```
lib/
├── core/        theme, localization, state, routing, utilities
├── data/        models and sample data
├── widgets/     shared UI components
└── features/    application screens
```
