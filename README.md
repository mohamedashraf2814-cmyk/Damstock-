# DAMSTOCK HOMES — Web App

Real estate marketplace web application for the Egyptian market, built with **HTML, CSS and JavaScript** (no frameworks).

Developed by **Soft Stream** — Software Programming & Digital Network.

## Run

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

```
index.html        App shell
css/style.css     Styles and brand theme
js/data.js        Developers, projects and properties
js/i18n.js        Arabic / English texts
js/app.js         Router, state and all screens
assets/icon.svg   App icon
flutter_app/      Flutter mobile version (Android / iOS)
```

## Features

- Arabic (RTL) and English
- Onboarding and phone number sign-in (demo code: 1234)
- Property listings with search, filters and sorting
- Developers and projects
- Resale and assignment listings
- Property comparison (up to 3)
- Interactive map with price pins
- Instalment calculator
- Viewing requests and inquiries
- Add property listing (4 steps)
- Favorites and user profile, saved in the browser
